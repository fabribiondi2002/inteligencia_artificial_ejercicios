## Cómo resolverlas

Con el entorno del repositorio ya configurado (ver [Quick start](../../README.md#quick-start)):

```bash
jupyter notebook
```

y elegí el kernel **"Python (IA)"** al abrir cada notebook. Podés usar como referencia las notebooks de [`../notebooks/`](../notebooks/).
