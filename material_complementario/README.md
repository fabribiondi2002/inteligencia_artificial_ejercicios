# Material complementario

Contenido para repasar las herramientas de base que se usan en todas las clases: Python, NumPy, Pandas, Matplotlib y Seaborn.

## [`notebooks/`](notebooks/)

11 notebooks tutoriales, cada una autocontenida:

| # | Notebook | Tema |
|---|---|---|
| 01 | [`primera_notebook`](notebooks/01_primera_notebook.ipynb) | Qué es Jupyter y cómo se usa |
| 02 | [`usando_python`](notebooks/02_usando_python.ipynb) | Repaso de Python (tipos, control de flujo, funciones) |
| 03 | [`usando_numpy`](notebooks/03_usando_numpy.ipynb) | Arrays y operaciones con NumPy |
| 04 | [`pandas_introduccion`](notebooks/04_pandas_introduccion.ipynb) | Series y DataFrames: lo básico |
| 05 | [`pandas_operando`](notebooks/05_pandas_operando.ipynb) | Selección, filtrado y operaciones sobre DataFrames |
| 06 | [`pandas_combinando_datos`](notebooks/06_pandas_combinando_datos.ipynb) | Merge, join y concat |
| 07 | [`pandas_agrupando_datos`](notebooks/07_pandas_agrupando_datos.ipynb) | `groupby` y agregaciones |
| 08 | [`pandas_fuentes_de_datos`](notebooks/08_pandas_fuentes_de_datos.ipynb) | Leer CSV, TXT, JSON, Parquet y Pickle |
| 09 | [`usando_matplotlib`](notebooks/09_usando_matplotlib.ipynb) | Gráficos básicos con Matplotlib |
| 10 | [`graficando_con_pandas`](notebooks/10_graficando_con_pandas.ipynb) | Los métodos de gráficos integrados de Pandas |
| 11 | [`usando_seaborn`](notebooks/11_usando_seaborn.ipynb) | Visualización estadística con Seaborn |

## [`ejercicios/`](ejercicios/)

8 notebooks de práctica **no entregables**, con espacios en blanco (`___`) para completar sobre los mismos temas — ver el [README de la carpeta](ejercicios/) para el detalle.

## Cómo abrirlas

Con el entorno del repositorio ya configurado (ver [Quick start](../README.md#quick-start)):

```bash
jupyter notebook
```

y elegí el kernel **"Python (IA)"** al abrir cada notebook.
