# Clase 1 - Introducción a Python

## Notebooks

- [`01_introduccion_a_python.ipynb`](01_introduccion_a_python.ipynb) — Primeros pasos, tipos de datos, control de flujo, listas, funciones.
- [`02_poo_python.ipynb`](02_poo_python.ipynb) — Programación Orientada a Objetos: clases, herencia, encapsulamiento, métodos de clase y estáticos.

## Cómo abrirlas

Con el entorno del repositorio ya configurado (ver [Quick start](../README.md#quick-start)):

```bash
jupyter notebook
```

y elegí el kernel **"Python (IA)"** al abrir cada notebook.
